# テストスイート（tests/）

本プロジェクトの自動テスト群です。  
対局ロジック、点数計算、データベース連携、および**対局中断・復帰（ドラフト保持）**の完全性を検証します。

---

## 1. テストの実行方法

プロジェクトルートで以下のコマンドを実行してください（単一コマンドで全テストが一括実行されます）。

```bash
# 仮想環境を使用する場合（推奨）
.venv\Scripts\python.exe tests/run_tests.py

# または
python tests/run_tests.py
```

※ `tests/run_tests.py` が自動的にパス解決および Streamlit / DB のモック設定を行うため、外部 DB や UI を起動せずに高速かつ安全に全件実行できます。

---

## 2. 各テストファイルの役割

| テストファイル | 検証対象と役割 |
| :--- | :--- |
| **`test_interruption_recovery.py`** | **【最重要】対局中断・セッション喪失・復元ライフサイクルテスト**<br>全10種類のアクション（リーチ・副露・ツモ・ロン・ダブロン・流局・途中流局・チョンボ・Undo・局修正）で直ちに最新ドラフトが保存されること、メモリ完全破棄（ブラウザリロード・クラッシュ）後に通常画面（`normal`）および直前の全スコア・本場・供託・カスタムルールが100%復元されることを検証。**本番DBには一切触れずメモリ上で完全遮断されています。** |
| **`test_game_logic.py`** | **対局ロジック・GameState の単体テスト**<br>連荘ルール（テンパイ連荘／アガリ連荘）、供託移動、アガリやめ・テンパイやめ・サドンデス・飛び終了の判定ロジックを検証。 |
| **`test_calc.py`** | **麻雀点数計算・順位点（pt）計算テスト**<br>符計算、翻数、役満、ウマ・オカ計算、五捨六入/四捨五入、チョンボ罰符計算の整合性を検証。 |
| **`test_identity_schema.py`** | **ID中心スキーマ・参加者紐付けテスト**<br>グループ・メンバーIDの整合性、同姓同名の許容、参加者テーブル（`game_participants`）の記録を検証。 |
| **`test_supabase_sync.py`** | **オンラインDB同期整合性テスト**<br>マイグレーションSQLの存在、リモート同期クエリの整合性を検証。 |

---

## 3. AIエージェントへの必須規約
- コード変更、リファクタリング、UI修正を行った後は、**必ず `python tests/run_tests.py` を実行し、全テストが 0 failed であることを確認すること**。
- 対局ロジック（`src/game_logic.py`）や対局画面（`src/views/game.py`）を修正した際は、特に `test_interruption_recovery.py` の全パスを必須チェックポイントとすること。
