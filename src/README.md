# src（アプリケーションコア）

麻雀記録・集計アプリケーションのコアロジックおよびUIモジュール群です。

## モジュール構成と責務

| ファイル / ディレクトリ | 責務と役割 |
| :--- | :--- |
| **`database2.py`** | **データベースアクセス・不可分トランザクション層**<br>V2正規化スキーマ（UUID v7、第3正規形、完全縦持ち）に基づくCRUD操作。対局・局・座席の完全アトミック保存（`save_game_record`）、集計クエリ、およびSupabaseとの分散ハイブリッド同期（選択的Push・全件Pull）。 |
| **`game_logic.py`** | **対局進行エンジン・状態管理**<br>`GameState` クラスによる対局状態の一元管理。アクション（和了・流局・チョンボ・リーチ・副露・Undo・局修正）の確定、自動ドラフト保存（`autosave_draft`）および中断復元。 |
| **`calc.py`** | **点数・スコア計算エンジン**<br>翻数・符数からの点数計算、ウマ・オカ（五捨六入/四捨五入）計算、チョンボ罰符計算の純粋関数群。 |
| **`constants.py`** | **定数・ルール定義**<br>公式ルールテンプレート（Mリーグ等）、役満・翻・符リスト、UIカラー・スタイル定数。 |
| **`cache_utils.py`** | **キャッシュ制御**<br>マスタ変更や対局保存時に Streamlit のデータ読み込みキャッシュを安全にクリアするユーティリティ。 |
| **`views/`** | **Streamlit UI画面コンポーネント**<br>・`home.py`: ホームナビゲーション<br>・`setup.py`: 対局設定（グループ・ルール・対局者選択）<br>・`game.py`: リアルタイム対局入力（和了・流局・チョンボ入力）<br>・`stats.py`: 成績集計・グラフ・相性マトリクス・レコード表示<br>・`data_manage.py`: オンライン同期・バックアップ・CSV入出力<br>・`rule_manage.py`: ルールテンプレート管理<br>・`group_manage.py`: グループ・メンバー管理 |
