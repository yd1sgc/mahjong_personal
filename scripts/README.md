# scripts

データベースのバックアップや、本番環境向けのマイグレーション適用など、継続的に運用・管理で使用するスクリプト群です。

## 同期・データ復旧ツール

* `find_unsynced_games.py`
  * **機能**: ローカルとオンラインでゲームID体系が異なる仕様を考慮し、参加者名とスコアの完全一致を利用して「ローカルにのみ存在する詳細成績データ」を抽出・特定します。
* `upload_specific_games.py`
  * **機能**: 標準の同期関数（`sync_to_supabase`）が抱える「特定の条件下で局データがサイレントに欠落する欠陥」を回避し、指定したゲームデータ（および依存するグループ・ルール等のマスタ）を欠落なく安全にオンラインへ直接アップロード（Upsert）します。
